Архитектура проекта

MovieHub построен по стандартной Django monolith-архитектуре с разделением на приложения (apps) по доменным зонам. Каждое приложение отвечает за свою часть бизнес-логики.

🎬 catalog

Ядро проекта. Title (фильмы/сериалы), Genre, Country, Person, Collection, Studio, Award. Главная страница, каталог, поиск, фильтры, подборки.

📺 streaming

Видеоплеер и стриминг. VideoAsset, Episode, SubtitleTrack, WatchProgress. Поддержка HLS/DASH, continue watching, PiP, субтитры.

✍️ reviews

Отзывы и рейтинг. Один пользователь — один отзыв на фильм. Оценки от 1 до 10. Модерация, unique_review_per_user.

❤️ library

Личная библиотека: избранное, история просмотров. Переключатель избранного через AJAX и API.

💰 billing

Монетизация: подписки, платежи, промокоды, рефералы. Готово к подключению Stripe/PayPal/ЮKassa.

👤 users

Пользователи: кастомная модель с email, username, avatar. Регистрация, вход, профиль с табами.

🔌 api

REST API v1 (DRF). Title, Reviews, Collections, Favorites, Playback. Swagger UI + ReDoc. Фильтры, поиск, пагинация.

🧱 core

Базовые модели (SeoModel, TimeStampedModel), валидаторы изображений, health check, миксины пагинации.

Модели данных

Ключевые модели и их связи. MovieHub использует единую модель Title для фильмов и сериалов — это упрощает каталог, поиск, избранное и историю.

Ключевое архитектурное решение: Title — единая модель для фильмов и сериалов. Поле type (movie/series) различает их. Это позволяет поиску, фильтрам, избранному и истории работать с одной сущностью, а не с двумя разными моделями.

📋 Следующие шаги

Инфраструктура полностью готова. Для включения переводов нужно:

  1. Обернуть строки в {% trans "..." %} в шаблонах
  2. Запустить makemessages -l en -l ky
  3. Заполнить переводы в .po файлах
  4. Запустить compilemessages
