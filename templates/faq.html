{% trans "Часто задаваемые вопросы" %}

{% trans "О платформе" %}

{% trans "LumiBox — это бесплатно?" %}

{% blocktranslate trimmed %} Да, LumiBox полностью бесплатен. Никаких подписок, скрытых платежей или пробных периодов. Все фильмы и сериалы доступны без ограничений. {% endblocktranslate %}

{% trans "Нужна ли регистрация?" %}

{% blocktranslate trimmed %} Регистрация не обязательна для просмотра каталога. Однако она открывает доступ к избранному, истории просмотров и персональным рекомендациям. {% endblocktranslate %}

{% trans "Как LumiBox отличается от других сервисов?" %}

{% blocktranslate trimmed %} Мы делаем акцент на удобстве поиска и навигации: умные фильтры, тематические подборки, персональные рекомендации. Никакой рекламы в плеере, никаких ограничений — только кино. {% endblocktranslate %}

{% trans "Просмотр и каталог" %}

{% trans "Почему не воспроизводится видео?" %}

{% blocktranslate trimmed %} Проверьте интернет-соединение и попробуйте обновить страницу. Если проблема сохраняется — напишите нам в Telegram или на почту, мы поможем. {% endblocktranslate %}

{% trans "Как найти фильм?" %}

{% blocktranslate trimmed %} Используйте строку поиска в верхней части страницы — она ищет по названию на русском и оригинальном языке. Также доступны фильтры по жанру, стране, году и рейтингу. {% endblocktranslate %}

{% trans "Как добавить фильм в избранное?" %}

{% blocktranslate trimmed %} На странице фильма нажмите кнопку «В избранное» — иконка сердца. Чтобы просмотреть избранное, откройте меню пользователя и выберите «Избранное». {% endblocktranslate %}

{% trans "Профиль и рекомендации" %}

{% trans "Как работают рекомендации?" %}

{% blocktranslate trimmed %} Система анализирует ваши просмотры и оценки, чтобы предлагать фильмы и сериалы, которые вам могут понравиться. Чем больше вы смотрите — тем точнее рекомендации. {% endblocktranslate %}

{% trans "Где посмотреть историю просмотров?" %}

{% blocktranslate trimmed %} В меню пользователя выберите пункт «История». Там отображаются все фильмы и сериалы, которые вы начали смотреть. {% endblocktranslate %}

{% trans "Как изменить данные профиля?" %}

{% blocktranslate trimmed %} Перейдите в «Профиль» через меню пользователя. Там можно изменить имя, аватар и другие настройки. {% endblocktranslate %}
