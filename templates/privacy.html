{% trans "Какие данные мы собираем" %}

{% blocktranslate trimmed %} LumiBox собирает минимально необходимый объём данных для обеспечения работы сервиса: адрес электронной почты, имя пользователя, историю просмотров и список избранного. Эти данные нужны для персонализации рекомендаций и сохранения ваших предпочтений между сессиями. {% endblocktranslate %}

{% trans "Как мы используем данные" %}

  • {% trans "Для формирования персональных рекомендаций" %}
  • {% trans "Для улучшения качества сервиса на основе агрегированной статистики" %}
  • {% trans "Для обратной связи по запросам в службу поддержки" %}

{% trans "Защита данных" %}

{% blocktranslate trimmed %} Мы используем современные методы защиты данных: шифрование паролей алгоритмом Argon2, защищённое HTTPS-соединение, Content-Security-Policy заголовки. Мы не передаём персональные данные третьим лицам и не используем их в целях, не указанных в данной политике. {% endblocktranslate %}

{% trans "Файлы cookie" %}

{% blocktranslate trimmed %} Мы используем минимальный набор технических cookie-файлов, необходимых для работы сессии и аутентификации. Сторонние аналитические сервисы (Google Analytics) могут устанавливать свои cookie только при наличии вашего согласия через настройки браузера. Мы не используем cookie для отслеживания вас на сторонних сайтах. {% endblocktranslate %}
