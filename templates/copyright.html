{% trans "Как работает LumiBox" %}

{% blocktranslate trimmed %} LumiBox — это каталог фильмов и сериалов, который хранит исключительно метаданные: названия, описания, год выпуска, жанры, информацию о съёмочной группе, рейтинги и отзывы пользователей. Мы не размещаем на своих серверах видеофайлы, не храним копии фильмов и не предоставляем возможность скачивания контента без согласия правообладателя. {% endblocktranslate %}

{% blocktranslate trimmed %} Все видеоресурсы, доступные для просмотра через наш плеер, предоставляются исключительно на основании лицензионных договоров с правообладателями или через официальные партнёрские интерфейсы. Ссылки на сторонние источники могут быть добавлены исключительно с согласия владельцев авторских прав. {% endblocktranslate %}

{% trans "Процедура подачи жалобы" %}

{% blocktranslate trimmed %} Если вы обнаружили в каталоге LumiBox контент, который нарушает ваши авторские или смежные права, пожалуйста, направьте уведомление на наш электронный адрес. Мы рассматриваем все обращения в строгом соответствии с действующим законодательством. {% endblocktranslate %}

{% trans "Необходимая информация для жалобы" %}

{% blocktranslate trimmed %} Для ускорения обработки вашего обращения, пожалуйста, включите в письмо следующие сведения: {% endblocktranslate %}

  • {% blocktranslate trimmed %} Точное указание произведения, в отношении которого заявляются права (название, год выпуска, ссылка на страницу в каталоге LumiBox). {% endblocktranslate %}
  • {% blocktranslate trimmed %} Информацию, подтверждающую ваше исключительное право на произведение (реквизиты лицензионного договора, свидетельства, иные документы). {% endblocktranslate %}
  • {% blocktranslate trimmed %} Описание характера нарушения и ваши требования по его устранению (удаление из каталога, изменение описания и т.д.). {% endblocktranslate %}
  • {% blocktranslate trimmed %} Ваши контактные данные для обратной связи: полное имя (для физического лица) или наименование организации, электронная почта, телефон. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Дату и подпись. Для юридических лиц — печать организации и подпись уполномоченного представителя. {% endblocktranslate %}

{% trans "Сроки рассмотрения" %}

{% blocktranslate trimmed %} Мы обязуемся рассмотреть ваше обращение в срок до 3 (трёх) рабочих дней с момента получения. В случае необходимости запроса дополнительной информации срок может быть продлён, о чем вы будете уведомлены дополнительно. {% endblocktranslate %}

{% blocktranslate trimmed %} После принятия решения по вашему обращению мы незамедлительно принимаем необходимые меры: удаляем или блокируем доступ к спорному контенту, корректируем метаданные либо предоставляем мотивированный отказ с указанием причин. {% endblocktranslate %}
