{% trans "О проекте LumiBox" %}

{# Mission #}

{% trans "Что такое LumiBox?" %}

{% blocktranslate trimmed %} LumiBox — это современная платформа-каталог фильмов и сериалов, созданная для тех, кто ценит качественное кино. Мы объединяем удобный поиск, интеллектуальные рекомендации, тематические подборки и персональную библиотеку в одном интерфейсе. {% endblocktranslate %}

{% blocktranslate trimmed %} Проект родился из желания сделать просмотр кино максимально удобным: без навязчивой рекламы, без сложных подписок, без необходимости разбираться в интерфейсе. Просто открываете — и находите то, что хотите посмотреть. {% endblocktranslate %}

{# Mission #}

{% trans "Наша миссия" %}

{% blocktranslate trimmed %} Мы верим, что хорошее кино должно быть доступно каждому. Наша миссия — создать удобный инструмент для поиска и каталогизации фильмов и сериалов, который помогает открывать новые произведения и не терять любимые. {% endblocktranslate %}

{% blocktranslate trimmed %} LumiBox — проект с открытым исходным кодом. Это значит, что любой разработчик может изучить код, предложить улучшения или использовать наработки в своих проектах. Мы строим платформу сообща, а не за закрытыми дверями. {% endblocktranslate %}

{# Why choose us #}

{% trans "Почему выбирают LumiBox?" %}

{% trans "Богатый каталог" %}

{% trans "Личная библиотека" %}

{% blocktranslate trimmed %} Сохраняйте фильмы в избранное, отмечайте просмотренные, возвращайтесь к недосмотренным. История просмотров и список желаемого всегда под рукой. {% endblocktranslate %}

{% trans "Современный дизайн" %}

{% blocktranslate trimmed %} Продуманный интерфейс с тёмной и светлой темой, адаптивная вёрстка для любых устройств, плавные анимации — смотреть кино на LumiBox одинаково приятно на компьютере, планшете и телефоне. {% endblocktranslate %}

{% trans "Безопасность и открытость" %}

{% blocktranslate trimmed %} HTTPS, Argon2-хеширование паролей, Content-Security-Policy заголовки и открытый исходный код, который может проверить любой желающий. Ваши данные в безопасности. {% endblocktranslate %}

{# FAQ #}

{% trans "Часто задаваемые вопросы" %}

{% trans "LumiBox — это бесплатно?" %}

{% blocktranslate trimmed %} Да, LumiBox полностью бесплатен. Никаких подписок, скрытых платежей или пробных периодов. Всё, что вы видите на сайте, доступно без каких-либо ограничений. {% endblocktranslate %}

{% trans "Нужна ли регистрация?" %}

{% blocktranslate trimmed %} Регистрация не обязательна для просмотра каталога. Однако она даёт доступ к избранному, истории просмотров и персональным рекомендациям. {% endblocktranslate %}

{% trans "Как добавить фильм в каталог?" %}

{% blocktranslate trimmed %} Каталог пополняется редакторами проекта. Если вы хотите предложить фильм или сериал — напишите нам через форму контактов. Мы рассмотрим все предложения. {% endblocktranslate %}

{% trans "Почему не воспроизводится видео?" %}

{% blocktranslate trimmed %} LumiBox — это каталог метаданных. Мы не храним видеофайлы на своих серверах. Воспроизведение возможно при наличии подключённого источника контента. Если видео не играет — проверьте интернет-соединение или обратитесь в поддержку. {% endblocktranslate %}

{% trans "Как связаться с разработчиками?" %}

{% blocktranslate trimmed %} Вы можете написать нам на hello@lumibox.app, в Telegram (@lumiboxxx) или открыть issue на GitHub. Мы всегда открыты к обратной связи и предложениям. {% endblocktranslate %}
